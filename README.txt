I AM YOU — film prop website
Open index.html to begin.
Type the exact loneliness prompt from the screenplay and press Enter.
Choose “Talk to Yourself” to open the I AM YOU welcome screen.
Click “Start a Conversation” to enter the scripted chatbot.

For hosting: upload the contents of this folder to a static hosting provider.
No backend, database, API key, or internet connection is required after hosting.
The interface is a fictional film prop and is not connected to the real ChatGPT service.
